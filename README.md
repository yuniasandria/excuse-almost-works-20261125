# The Excuse That Almost Works

A program that writes the single line a gamer texts the boss to skip work
on GTA 6 launch week: one line of plain text, at most 20 words, reading
like something a real person would send in a hurry.

The entry is a specific, boring, checkable-sounding detail — a burst pipe
upstairs and a ceiling coming down — the kind of mundane mishap a tired
manager would almost believe, rather than a dramatic lie.

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, 19 words, under 140
characters). Pure Python standard library, deterministic: every run writes
byte-identical output.
